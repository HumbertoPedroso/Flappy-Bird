# Flappy Bird Simples

Projeto escolar feito com **HTML, CSS e JavaScript puro**.

## Como jogar

1. Abra o arquivo `index.html` no navegador.
2. Aperte **Espaço** ou clique/toque na tela para fazer o pássaro subir.
3. Desvie dos canos verdes para ganhar pontos.
4. Se bater em um cano ou sair da tela, o jogo termina.
5. Use o botão **Reiniciar** ou pressione Espaço para jogar novamente.

## Arquivos

- `index.html`: estrutura da página e área do jogo.
- `style.css`: aparência da página.
- `script.js`: física, canos, colisões, pontuação e controles.

Sem bibliotecas externas e sem instalação.
